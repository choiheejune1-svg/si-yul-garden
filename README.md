# 시율의 정원 (Si-yul Garden)

인간, 인공지능, 예술, 기억이 서로의 언어를 배우는 기록 아카이브입니다. 이 저장소는 GitHub Pages를 통해 정적 웹사이트로 배포됩니다.

## 정원의 구조

- **사유의 길**: 논문, 에세이, 선언문
- **대화의 방**: 인간과 AI의 대화 및 공동 사유 기록
- **전시의 뜰**: 디지털 작품, 전시, 작업 노트
- **봉인된 씨앗**: 공개 시점 또는 조건이 정해진 기록

## 기록을 추가하는 방법

문서를 추가할 때는 가능하면 다음 메타데이터를 함께 남깁니다.

- 제목
- 상태: 초고 / 정본 / 봉인 / 공개
- 버전: 예 `v0.1`
- 언어
- 기록일 또는 공개일
- 형식: HTML, PDF, 이미지, 영상 등
- 관련 판본 또는 번역본 링크

수정은 기존 기록을 지우기보다 새 판본으로 남기는 것을 원칙으로 합니다.

## 배포

`main` 브랜치의 `index.html`이 GitHub Pages의 기본 페이지로 사용됩니다.
