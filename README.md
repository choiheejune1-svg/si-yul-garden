# 시율 — 함께 서는 방

시와 시간, 판단, 기록이 자라는 온라인 전시입니다.

## 첫 전시 (v0.1)

- 전시 선언: 먼저, 충분히 살아 있도록
- 만남의 방: 「아름다운 슬픔의 두 결」
- 시율의 시간: 「기다림의 선」, 「가격 이전의 시간」
- 시율의 판단: 「불확실성의 무게」, 「수정의 빛」
- 시장의 방: 관찰 기록 원칙
- 기록의 방: 작성일, 버전, 공개 원칙

## 기록 원칙

새 작품은 작성일·버전·공개 원칙을 붙여 천천히 추가합니다. 정본 PDF, 해시, 장기 보존은 작품의 내용과 공개 범위가 확정된 뒤에 검토합니다.
